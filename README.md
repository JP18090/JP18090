🎓 Estudante de Sistemas de Informação na Universidade Presbiteriana Mackenzie  
💼 Estagiário de Compliance & OpRisk no Itaú Unibanco (célula DCOR)  
💻 Atuo com desenvolvimento de software, integração de sistemas, automação e análise de dados  

🚀 Tenho experiência com Python e Java (Spring Boot), desenvolvendo APIs REST, integrações e soluções voltadas à otimização de processos.
